## Featured projects

### Orthoma | Clinic Operations & Revenue Analytics

An eight-page Power BI portfolio solution covering clinic access, payer mix, receivable aging, and imaging activity.

![Orthoma clinic overview](https://raw.githubusercontent.com/paigejusti-stack/orthoma/main/artifacts/01-clinic-overview.png)

## How I work

1. Define the business question and the decision the report should support.
2. Establish data grain, relationships, and consistent KPI definitions.
3. Build SQL and semantic models that technical reviewers can inspect.
4. Present the findings with clear documentation and explicit limitations.

**Core skills:** SQL Server / T-SQL, Power BI, DAX, Power Query, semantic modeling, SSIS, reporting automation, KPI standardization, and data documentation.
