SQL / REPORTING VIEW

A stable interface
for the report.

The model consumes curated rpt.* views. That separates the reporting interface from the underlying warehouse tables.

Read the SQL source ↗
rpt.FactVisit.View.sql EXCERPT
CREATE   VIEW [rpt].[FactVisit] AS
SELECT VisitKey, VisitID, VisitDateKey, LocationKey, ProviderKey, PayerClassKey,
       ServiceLineKey, VisitTypeKey, PayerName, BodyPart, ReferralSource,
       ArrivalTime, ArrivalHour, MinutesToRoom, MinutesToProvider,
       VisitDurationMinutes, XrayPerformed, MRIOrdered, MRILocation,
       InjectionPerformed, ChargeAmount, AllowedAmount
FROM fact.Visit;
DAX / METRIC ELIGIBILITY

The denominator
is a design decision.

Wait-time percentages use eligible visits. Blank and negative intervals are excluded so the denominator matches the question.

Read the DAX source ↗
_Measures.tmdl DAX BODY
D2P Eligible Visits =
COUNTROWS (
    FILTER (
        Visits,
        NOT ISBLANK ( Visits[Minutes to Provider] )
            && Visits[Minutes to Provider] >= 0
    )
)
